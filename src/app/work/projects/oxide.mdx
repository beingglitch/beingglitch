## Overview

Oxide is a file encryption tool with a deliberately small surface: encrypt a file, decrypt a file,
and get modern cryptographic defaults without having to choose them yourself.

## Key Features

- **Modern cryptography** with sensible, non-configurable defaults — the safest option is the only option
- **Fast** — Rust, no runtime, streaming over large files
- **Simple CLI** that does not require understanding the primitives underneath

## Technologies Used

- **Rust**
