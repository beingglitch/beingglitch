## Overview

Quark is a game engine written in Rust, covering real-time graphics, physics simulation, and
AI-driven agents. They are the same three problems robotics simulation asks you to solve, approached
from the other direction.

## Key Features

- **Real-time rendering** pipeline
- **Physics simulation** integrated into the core loop
- **Agent AI** for autonomous entities in the scene

## Technologies Used

- **Rust**
