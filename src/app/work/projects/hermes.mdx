## Overview

Hermes is an algorithmic trading engine for real-time market analysis and execution. The design
priorities are speed, precision, and scalability: market data has to be ingested, analysed, and
acted on inside a window where being late is the same as being wrong.

## Key Features

- **Real-time market analysis** over live data feeds
- **Execution engine** built for low-latency order placement
- **Scalable architecture** intended to run many strategies concurrently
