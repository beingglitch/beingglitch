## Overview

Augury is an analytics and prediction service built around a FastAPI backend, with an AI layer that
answers questions over a private corpus rather than from the model's own weights.

## Key Features

- **Retrieval-augmented generation**: answers are grounded in indexed source documents, with retrieval sitting between the question and the model.
- **LangGraph workflows**: multi-step reasoning expressed as an explicit graph, so a run can branch, loop, and be inspected rather than disappearing into one opaque call.
- **LangChain integrations**: document loading, chunking, embeddings, and vector store access.
- **FastAPI service layer**: the whole pipeline exposed over HTTP.

## Technologies Used

- **Python** with **Poetry** for dependency management
- **FastAPI** + **Uvicorn**
- **LangGraph** for agentic, stateful workflows
- **LangChain** for the retrieval and embedding pipeline
