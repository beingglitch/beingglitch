## Overview

Bullseye is a target practice simulator that runs entirely in the browser. No install, just a URL.
The interesting constraint is the input: instead of a mouse, it takes a RadioMaster Pocket, a real
RC transmitter, as the controller. Physical gimbals and switches make aiming a matter of steady
hands rather than steady wrists.

## Key Features

- **Runs in the browser**: the whole simulator ships as a web app, so a session is a link away.
- **Hardware input**: a RadioMaster Pocket connected over USB, read as a real input device so its
  sticks and switches map onto aiming and controls.
- **Multiplayer**: shared ranges where several people can practice in the same session.
- **Scoring and feedback**: shot placement and accuracy tracked over a session rather than a single
  shot at a time.

## Status

In development. Currently working through the input pipeline and the networking model for shared
sessions.
