## Overview

Sharing environment variables is a problem every team solves badly — pasted into chat, or handed to
a SaaS vault that now holds every secret you have. Whisper takes the third path: peer-to-peer
synchronization between developer machines, so secrets move directly between the people who already
have them.

## Key Features

- **No central server**: environment state syncs directly between peers.
- **Rust CLI**: a single fast binary, no runtime to install.
- **Drop-in workflow**: works against the `.env` files projects already use.
